# git-commit

Write Conventional Commit messages that match what experienced engineers actually merge — short, why-focused, never a transcript of the diff. Triggers automatically on requests like "commit this", "squash these", "amend", or whenever Claude is about to run `git commit`.

## Contents

- `skills/git-commit/SKILL.md` — full workflow, anti-patterns, examples.
