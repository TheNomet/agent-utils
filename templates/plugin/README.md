# example-plugin

Short description of what this plugin gives the user when installed.

## Contents

- `skills/example-skill/` — auto-loaded workflow guidance
- `commands/example-command.md` — `/example-command` slash command
- `agents/example-agent.md` — specialized subagent
- `scripts/example.sh` — helper script callable from skills/commands

## Install

Once the marketplace is added (see repo root README):

```
/plugin install example-plugin@ed-ct-agent-utils
```
